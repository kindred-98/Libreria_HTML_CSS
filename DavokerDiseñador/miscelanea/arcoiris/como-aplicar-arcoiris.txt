================================================================
EFECTO ARCOÍRIS - CÓMO APLICARLO A CUALQUIER ARCHIVO .CSS
================================================================

PASO 1 - COPIA EL CSS
---------------------
Copia TODO el archivo "arcoiris.css" dentro de tu hoja de estilos
(o enlázalo desde tu HTML con):

    <link rel="stylesheet" href="ruta/arcoiris.css">

El archivo es 100% portable: no depende de ningún otro estilo,
de librerías ni de JavaScript. Contiene:
  · La clase .efecto-arcoiris
  · 1 @keyframes: arcoiris-movimiento


PASO 2 - AÑADE EL TEXTO EN TU HTML
-----------------------------------
    <span class="efecto-arcoiris">Tu texto</span>

Ejemplo real sobre un título:

    <h1><span class="efecto-arcoiris">Mi web</span></h1>


VENTAJA FRENTE AL EFECTO GLITCH
-------------------------------
Este efecto NO necesita el atributo data-text: solo la clase.


QUÉ HACE
--------
Un degradado arcoíris (rojo → naranja → amarillo → verde →
azul → violeta → rojo) recorre las letras de forma continua
e infinita, 3,5 segundos por vuelta, sin cortes ni pausas.
Funciona con background-clip: text (navegadores modernos).


AJUSTES FÁCILES
---------------
· Más lento: cambia 3.5s por 6s.
· Más rápido: cambia 3.5s por 1.5s.
· Cambiar colores: edita los valores del linear-gradient
  (empieza y termina en #ff0000 para que el bucle sea
  continuo: si cambias el último, cámbialo también al rojo
  o el final "saltará").
· Para texto en negrita, añade font-weight: bold; donde
  quieras usarlo.
