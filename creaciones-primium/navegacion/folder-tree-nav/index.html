Design · Overview

Project overview

The site redesign replaces a nine-year-old brochure site with a documentation-first structure: fewer pages, longer pages, and a search index that covers every sentence we publish. Work started in January and runs to the end of June, with two people on design and three on build.

Design · Assets

Assets

Brand marks, the type scale, the colour tokens and the six photography sets we are allowed to use. Every file is exported twice: one version for the screen and one for print, with the print set carrying the fixed CMYK build.

Files are named by purpose rather than by version, so mark-primary is always the current mark and the superseded ones live in the archive folder behind it.

Finance · Retrospective

Retrospective

What the team agreed at the end of the structure phase: the audit should have happened before any design work, the weekly demonstration is worth two status reports, and the tree view of the project has become the way everyone describes the work in meetings.

Two actions came out of it and both are in the tasks list above — the keyboard pass, and the image compression work that was quietly deferred three times.
