01 / Terminal

A shell that remembers every pane

The terminal splits horizontally or vertically, keeps a scrollback of one hundred thousand lines per pane, and restores the whole arrangement — pane sizes, working directories and even the environment variables you set in a hurry — the moment the session returns.

Output is rendered through a GPU text path, so a build log scrolling at full speed does not take the compositor with it. Blocked commands show a hairline progress rule at the bottom of the pane instead of a spinner, and a finished pane turns its edge green from across the room.

02 / Files

Columns that never make you go back

The file manager opens every level as a column to the right of the last one, so the path you walked is still on screen when you reach the file you wanted. Preview columns render documents, images and audio without launching anything.

Search runs across names, contents and metadata in one pass, and results appear as you type into a column of their own. Every operation is reversible for ten minutes, including a move across two disks that failed halfway through.

03 / Mail

Offline first, threaded second

Every message is stored locally the moment it arrives, so reading, searching and writing all work with the radio off. Sending queues in the background and tells you only when the queue is empty, not every time a message leaves.

Threads collapse to a single subject with the participants stacked at the right edge, and a conversation you have answered twice in a week surfaces at the top of the list with its previous reply attached. Labels are keystrokes, never mouse trips.

04 / Calendar

Weeks you can actually read

The calendar shows a working week at a glance with travel time drawn between events rather than listed underneath them. Anything that would make you late is shaded at the edge before you accept it.

Scheduling someone else opens their free hours as a set of columns you can drag into, and the invitation carries the room, the dial-in and the document you will be discussing. Reminders fire as the dock ring pulses, never as a modal.

05 / Notes

Plain text with a careful preview

Notes are markdown files in a folder you own, synced wherever you decide to sync them. The editor shows the raw text on the left and the rendered page on the right, and the two stay aligned line for line as you type.

Backlinks appear in a margin column as soon as a title is mentioned twice, and the whole collection can be rebuilt into a static site with one command. Nothing in this module requires an account.

06 / Settings

One place, plain words, no categories tree

Settings are a single searchable list written in sentences rather than a hierarchy of nested panels. Typing dock narrows the list to the launcher immediately, including the zoom radius and the easing curve used by the magnetism.

Every change previews live and undoes itself if you do not confirm within five seconds, so experimenting with the dock is free. Accessibility settings sit at the top of the list, not behind an advanced switch.
